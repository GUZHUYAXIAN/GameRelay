# GameRelay · 游序实施计划

状态：开发候选已形成，36 项自动测试通过、便携独立解压验证通过，MIT 已确认。真实绑定核对与游戏联调仍待完成。

阶段进展：接口只读核对、调度/进程管理/GUI、当前自动化验证、文档、性能测量与便携候选已完成。公开前按白名单检查文件，再核实远端与待推送历史。实际启停前按联调提案取得相应授权；用户亲自执行桌面交互和原脚本设置。

1. 核对目录、工具链、本机客户端版本、自动执行接口及独占资源。形成脱敏兼容矩阵；个人核对资料仅放入忽略的 private/。
2. 分离领域模型、调度器、原子持久化、进程观察与安全恢复。通过可控模拟进程验证并发、排队、补跑、外部覆盖、崩溃窗口、资源残留和一次重试。
3. 完成中文 WinForms 界面、托盘、可取消扫描、计划编辑和适配器。真实联调另列对象、步骤和影响，获授权后执行；不自动启用发现项。
4. 构建便携包，独立解压验证、测量资源消耗，提供用户手动验收步骤和完整文档。
5. 审核实际分发依赖，取得许可证选择，核实 GitHub 身份和仓库冲突；审计全部待公开文件与历史后按已有授权提交、创建公开仓库、推送并回读验证。

## 实施约束

- 不启停真实脚本、游戏、模拟器或 VMware；不代用户点击界面。
- 不修改原脚本配置、账号、ADB、内置计划；不安装新工具或修改全局设置。
- 不以打开窗口替代自动执行，不以进程退出替代任务成功。
- 只清理可验证归属的对象；无法确认则阻止重试并要求处理。
- 新计划无创建前欠账，示例无活动计划，Alas 仅观察，鸣潮保护手动持久化。
- 源码、模拟测试、便携构建、真实联调、公开上传分别记录证据。
