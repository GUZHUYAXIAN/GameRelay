## 性能实测

采用相同 WinForms 消息循环与后台观察周期（5 秒），11 个停用实例、0 条活动计划。窗口离屏，无游戏启动。预热约 3 秒，再采样约 30 秒。

| 指标 | 结果 |
|---|---|
| 管理器工作集 | 52.47 MiB |
| 采样期峰值工作集 | 53.45 MiB |
| 管理器私有内存 | 35.99 MiB |
| 管理器 CPU 用时 | 890.625 ms / 29.998 s |
| MuMu 只读查询子进程 CPU 用时 | 1312.5 ms / 同期 |
| 管理器 CPU 占本机总容量 | 约 0.148% |
| 管理器与查询子进程合计占本机总容量 | 约 0.367% |

查询使用已安装的 MuMuManager，只读、不启停模拟器。CPU 总量按本次机器逻辑处理器数量归一化；不同机器不可直接套用。工作集仅为管理器进程，不包含外部模拟器、原脚本或查询进程的瞬时内存。

扫描测量：访问 2022 个目录，发现 11 项，耗时 993 ms，CPU 用时 937.5 ms，独立扫描诊断进程峰值工作集约 30.85 MiB。此次结果有操作系统文件缓存，不能当作首次冷扫描保证。

## 便携与发布状态

便携 ZIP 已在项目目录外的全新中文/空格临时目录独立解压。从该目录运行 EXE 完成数据往返，离屏渲染 5 页，EXE 与构建文件 SHA-256 相同；包内没有私有库存、活动计划、测试程序或上游资源。无需源码目录。

新解压后立即执行曾复现核心 DLL 的共享冲突（FileLoadException，0x80070020）。已将依赖预加载放在独立启动边界内，仅对共享/锁冲突等待最多约 5 秒；依赖缺失、损坏或持续占用会明确报错，调度不启动。等待仅发生在依赖加载阶段，不重试应用执行或游戏启动。受控短暂锁、持续锁、损坏 DLL 三项真实子进程回归通过；未关闭安全软件或修改系统设置。占用文件的外部进程尚未定位。
