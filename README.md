# GameRelay · 游序

轻量级 Windows 游戏脚本调度管理器，支持多实例排队、定时启动与并发控制。

**让游戏脚本按时启动、有序接力。**

当前版本：0.1.0 开发候选，采用 [MIT 许可证](LICENSE)。调度及 Windows 模拟进程测试已通过，真实游戏联调尚未完成。

## 功能

- 中文 WinForms 界面：首页、脚本实例、计划、运行记录、设置。
- 普通任务默认最多 3 组；手动鸣潮保护开启后最多 1 组，保护状态持久保存。降低上限不会结束现有任务。
- 独立实例与独占资源分别检查，谁完成并释放资源就补位。Alas 仅观察、不计普通名额。
- 每天多个时间点、指定星期、批量计划、同时间顺序；长期离线欠账按同一计划合并一次。
- 外部程序保守占位，覆盖该轮计划但不记为成功；不会被自动清理。
- 原子保存状态与一次备份；启动意图先写盘。重启后不自动继承进程清理权限。
- 每项默认 120 分钟超时，可关闭；归属可确认且清理结果正常时最多重试一次。资源残留或归属不明会要求处理。
- 关闭窗口收起至托盘；暂停只阻止新启动，彻底退出后已启动程序继续运行。

## 使用

需要 Windows 10/11 x64 与 .NET Framework 4.8。无需安装 Python、Node 或游戏框架。解压整个便携目录到可写位置，运行 `GameRelay.exe`。程序不会设置开机自启或安装服务。

1. 在设置中配置扫描目录（默认 E 盘），点击脚本页“扫描目录”；也可手动选择入口。
2. 新发现项默认停用。核对独立配置、模拟器/游戏目标、自动执行方式和完成后退出设置。
3. 在脚本页编辑别名、参数、超时、顺序；设置原脚本后重新读取适配，再确认能力。
4. 启用所需实例并创建自己的计划，或点“立即运行”进入队列。安装包没有活动示例计划。

详细操作见 [使用说明](docs/USER_GUIDE.md)、[兼容表](docs/COMPATIBILITY.md) 和 [联调验收](docs/ACCEPTANCE.md)。

## 兼容边界

MAA 与 MaaFramework 使用不同适配器。MFAAvalonia、MFW、MaaPiCli 的参数及配置也独立处理；同名 EXE 根据安装目录区分。上游文件指纹变化会阻止继续使用未经核对的参数。

当前核对范围包括 MAA 6.18.0、旧 MFAAvalonia 1.8.7/2.2.7、一个具有实例命令行接口的 MFAAvalonia 提交，以及带旧参数说明的 MFW。不能承诺任意版本零配置适配。AALC 当前可发现、登记和显示状态，尚无本版自动执行适配；不会提供可点击的虚假启动功能。OKWW 不由本版启动、停止或重试。

“程序已打开”不等于“任务正在执行”，“已退出”不等于“成功”。当前普通客户端默认显示“已退出，结果未确认”。只读接口核对、模拟测试和真实运行验收是不同层级。

## 开发

在项目根目录使用 Windows PowerShell 或 PowerShell 7：

```powershell
.\build.ps1 -Test
.\package.ps1
```

构建使用系统 C# 编译器与 .NET Framework 库，不下载第三方依赖。便携文件在 `dist/`，不包含个人数据。详情见 [构建与测试](docs/BUILD.md)、[架构与扩展](docs/ARCHITECTURE.md)、[贡献指南](CONTRIBUTING.md)。

GameRelay 是独立项目，不代表 MAA、MaaFramework、Alas、OKWW 或其他项目官方，不包含这些项目的程序、资源、模型或账号配置。

## 数据与反馈

数据位于便携目录的 `data/`。请连同程序备份和迁移，且不要上传该目录。损坏数据不会自动回滚到旧触发游标，以避免重复启动。反馈前先阅读 [常见问题](docs/FAQ.md) 并脱敏。
